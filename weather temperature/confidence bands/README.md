## Overview 

#### `functions.R` contains (each month of 1952 - 1972 and 2000 - 2025)
-  calculation of variance 
-  integral of delta test with construction of 95%-confidence bands
-  calculation of diagonal of long run covariance matrix
-  dependent Multiplier Bootstrap on non centered difference function
-  difference function test (not centered) with construction of 95%-confidence bands
-  calculation of diagonal of linear projection (P) of long run covariance matrix
-  dependent Multiplier Bootstrap on centered difference function
-  centered difference function test with construction of 95%-confidence bands
